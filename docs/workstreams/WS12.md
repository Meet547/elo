# Product routes and records

The lobby, profile, leaderboard, practice, sign-in, settings, private rooms, ranked, match history and verification each have a URL. Completed private games create one unrated history row per participant. A permanent room instance ID links these rows to completed hand evidence, even after invitation expiry. The participant archive projects actions, awarded pots and disclosed cards. Public proof reads remain separate.

Practice state stays in the browser tab and the start screen describes reload behavior. Account settings provide data export and closure. Terms and privacy pages identify their pending owner approval. Worldwide minor consent and approved legal copy remain launch gates.

`npm run test:private-history` covers concurrent completion, owner authorization, rating invariance and survival after room deletion. `npm run smoke:browser` covers the browser paths listed in the verification report.
