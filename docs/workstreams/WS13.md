# Verification

GitHub Actions uses a fresh PostgreSQL database for each isolated test, applies the committed migrations, and runs typecheck, lint, unit and engine tests. The engine invariant suite checks 100,000 seeded hands. Ranked replay checks 1,000 repeated terminal commands and preserves both rating and history. Settlement and command crash fixtures exercise transaction rollback.

The production harness builds and starts both Next.js services and the backend deadline worker. Chromium uses two independent contexts for private seed exchange, ranked readiness, keyboard play through all ten hands, a reload during the first hand and archived results. The profile and active table are checked for horizontal overflow at 360, 390, 768 and 1280 pixels. Axe scans the profile, settings, practice landing and leaderboard with WCAG A and AA tags. The scan covers the tested states. Screen-reader usability and complete conformance need separate manual review.

The incremental test upgrades the prior PostgreSQL schema with existing room, hand and rating rows. The separate SQLite rehearsal tests a consistent legacy backup, import and fresh Postgres restore. CI uses synthetic SQLite rows. A local approved history copy was independently rehearsed with 47 players, 235 history rows and one room with matching hashes.

The 500-spectator k6 test runs locally in isolation. See [realtime evidence](WS7.md) and the later [protected-room run](../../FAIRNESS.md).
