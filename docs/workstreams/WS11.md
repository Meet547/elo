# Practice cost and ranked moderation

Practice uses the existing browser heuristic with a restricted bot view and a bounded think delay. The Cloud decision route and model credentials were removed. Practice decisions create zero model calls and zero model spend, so a server model quota and spend alert have no workload in this version.

Verified identities on the admin allowlist can open Ranked moderation in account settings. Review uses the latest 500 matches in seven days and shows the latest 100. Pair counts, wins over recorded matches, draws, shared-network signals and fast ten-hand completions inform manual review. Flags do not automatically modify a match or account.

An administrator supplies a reason to void an open ranked match or reverse a settled result. An open void closes the room and releases seats in the same transaction as its audit row. A reversal adds the exact opposite of each original rating delta to the current rating, adjusts the original match’s counters and keeps the original settlement and history. The reversal also appears in the owner’s rating timeline and daily accounting. Later match results and RD remain as recorded. The service rejects a reversal while either participant is queued or when exact compensation would cross the supported rating bounds.

The admin command uses existing idempotency receipts and a unique moderation row per match. The isolated test covers access control, pair signals, simultaneous reversal attempts, preserved history and an open proposal void. The production smoke checks that the former model route returns 404.
