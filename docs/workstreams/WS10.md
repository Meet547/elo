# Ratings and statistics

See [ratings rules](../RATINGS.md) for the formula, inactivity periods, placement and the daily check. The owner’s history endpoint returns lifetime totals and a bounded recent ledger from one consistent snapshot. Chart x-coordinates and scrub selection use actual timestamps. The new isolated regression uses 80 owner results and an unrelated account to catch truncation and privacy errors. It also verifies Glickman’s reference result, time-based plotting, inactivity and unexplained ledger movement.

Run `npm run test:rating-statistics` against the local Postgres test harness.
